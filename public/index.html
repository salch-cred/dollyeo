01 — HOW IT WORKS

A narrow window.
A fair process.

Four verifiable steps replace opaque calls, spreadsheets and discretionary access.

01

A protected transfer enters

The sender opts into a short challenge window for high-value transfers. Outside the window, settlement is final.

OPT-IN BY THE SENDER
02

An issuer attests

A verified bank, VASP or authority signs a reason, case reference and automatic expiry using Dojang.

NO PRIVATE ADMIN KEY
03
✦✦

Settlement pauses

The protected account validates the attestation and pauses only the disputed transfer until review completes.

PUBLIC & TIME-LIMITED
04
₩

Funds return—or release

A valid decision returns value to the victim. If no decision arrives, the contract releases automatically.

03 — THE NON-NEGOTIABLE

No backdoor.
No hidden freeze.
No exceptions.

Dollyeo is not a custodial freezing service. It is a transparent protocol for opt-in protected accounts and externally attested due process.

function verifyOrder(
  Attestation calldata order
) external view returns (bool) {
  // issuer + reason + expiry
  return dojang.verify(order)
    && order.expiresAt > block.timestamp
    && protected[order.account];
}
